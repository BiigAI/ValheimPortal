# Changelog

All notable changes to the Bifrostheim server web portal are documented in this file.

## v1.1.0

### Added
- **Discord Integration**: Live Discord alerts for player joins, boss defeats, player deaths, and server status.
- **Quick Save Shortcut**: Use `⌘S` or `Ctrl+S` anywhere in the portal to instantly save configuration changes.

### Improved
- **Dashboard Redesign**: Unified visual layout across all tabs with simplified controls and sticky action headers.
- **Server Performance & Security**: Reduced background server overhead, smoother world saves, and hardened web security.

### Fixed
- Fixed an issue where server FPS calculation could trigger background Unity warnings.


## v1.0.1

### Fixed
- Fixed an issue in Characters Vault where single bound character records appeared as separate rows per property instead of a single table row.
